# Micronaut Test JUnit 5

[English](README.md) | [简体中文](README.zh-CN.md)

An adapter for common `@MicronautTest` configuration from Micronaut Test JUnit 5 5.1.0, published as `micronaut.test:junit5:1`. `micronaut/test/junit5/Main.norm` verifies real annotation lowering. `norm test` wraps the JUnit Platform and Micronaut Test Extension lifecycle; real DI and `@MockBean` acceptance are covered by `MicronautTestBindingIntegrationTest`.
