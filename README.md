# Micronaut Test JUnit 5

[English](README.md) | [简体中文](README.zh-CN.md)

The [module](micronaut/test/junit5/module.norm) binds `@MicronautTest` configuration. The independent [binding example](examples/binding/Main.norm) checks annotation lowering. `norm test` wraps the JUnit Platform and Micronaut Test Extension lifecycle; `MicronautTestBindingIntegrationTest` covers real DI and `@MockBean` behavior.
