# micronaut-test-junit5 sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies @MicronautTest and JUnit integration. The runnable scenario is owned by [micronaut-test](https://github.com/normlanguage/micronaut-test/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../examples/acceptance/sample/test/module.norm).
